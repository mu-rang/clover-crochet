네잎클로버 · 한 장씩 따라 뜨기

1. ZIP을 모두 압축 해제한 뒤 index.html을 여세요.
2. 첫 화면에서 완성본과 전체 코 수 도안을 볼 수 있습니다.
3. 뜨기 시작을 누른 뒤 이전·다음 버튼으로 10단계를 넘겨 보세요.
4. 키보드 좌우 화살표와 모바일 좌우 밀기도 지원합니다.
5. 그림을 누르면 확대됩니다. 상세 동작과 단계별 도안은 펼쳐 볼 수 있습니다.

도안 수정
- 도안상 오른쪽 아래 잎부터 반시계 방향으로 잎 1→2→3→4 순서를 표시했습니다.
- 각 잎의 내려오는 사슬 4코 다음에 가운데 원으로 돌아가는 빼뜨기를 배치했습니다.
- 마지막 빼뜨기는 잎 4의 사슬 끝, 줄기 왼쪽의 가운데 원 연결 위치입니다.
- 잎의 두길긴뜨기와 빼뜨기는 가운데 원의 구멍에 넣습니다.
